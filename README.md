# LANDVILLA

LANDVILLA is a modern Indian real estate marketplace for buying, selling, and renting properties.

## Project Goals

- Property listings for buyers, sellers, and renters
- Broker profiles and verification
- Buyer enquiries and lead management
- Featured property promotions
- Secure payment integration
- Mobile application support

## Repository Structure

The project source code will be organized into the following areas:

- `backend/` — Backend API and business logic
- `frontend/` — Mobile application and frontend source
- `docs/` — Setup, deployment, and handover documentation
- `scripts/` — Development and maintenance scripts
- `tests/` — Automated tests

Some directories may not be present until the application source code is transferred.

## Development

This repository uses the `dev` branch for development and the `handover` branch for the verified source handover.

Setup instructions will be documented after the complete application source code is added.

## Security

- Never commit real `.env` files, API keys, passwords, tokens, private keys, or signing credentials.
- Use `.env.example` files containing placeholders for configuration documentation.
- Keep production credentials in a secure environment or secrets manager.

## Status

The GitHub repository is being prepared for the LANDVILLA source-code transfer and independent infrastructure setup.
